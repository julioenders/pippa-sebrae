Sobre o PIPPA Consultas Publicas

O que e o Monitor de Consultas Publicas?

Ferramenta de incidencia pre-normativa que monitora audiencias publicas, seminarios e reunioes deliberativas na Camara e no Senado. O objetivo e identificar oportunidades para o SEBRAE se posicionar ANTES que as normas sejam publicadas — complementando o PIPPA Regulatorio, que monitora normas ja publicadas no DOU.

Fontes de Dados

  • Camara dos Deputados: API Dados Abertos v2 — /eventos (filtrado por tipo: audiencia publica, seminario, reuniao deliberativa). Periodo: 3 meses para tras e 2 meses para frente.
  • Senado Federal: API Dados Abertos — /plenario/agenda/mes/{YYYYMM} (filtrado por tipo: audiencia, debate, sabatina). Periodo: 4 meses.

Classificacao de Relevancia SEBRAE

Cada audiencia/consulta e verificada contra uma lista de palavras-chave relevantes para MPEs. O titulo e o orgao sao analisados automaticamente:

  • Nucleo MPE: micro, pequena, MEI, Simples, empreendedor
  • Regulatorio: regulamentacao, tributario, desburocratizacao, simplificacao
  • Economico: credito, fomento, inovacao, startup, licitacao, compras publicas
  • Institucional: Sebrae, Sistema S, SENAI, SESC
  • Setorial: turismo, agronegocio, exportacao, importacao

Status das Consultas

  • Aberta: Em andamento ou com data entre inicio e fim no periodo atual
  • Futura: Data de inicio ainda nao chegou
  • Encerrada: Data fim ja passou

Ordenacao

Consultas abertas aparecem primeiro, seguidas das futuras e encerradas. Dentro de cada grupo, as relevantes para o SEBRAE tem prioridade.

Limitacoes

  • Nem todas as audiencias publicas sao registradas nas APIs — algumas comissoes publicam apenas no site.
  • Consultas publicas de agencias reguladoras (ANVISA, ANATEL, ANP) nao estao contempladas nesta versao — exigem integracao com a API do Participa+ Mais Brasil.
  • APIs publicas sem SLA — sujeitas a instabilidade.
