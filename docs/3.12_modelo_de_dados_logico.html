3.12 — Modelo de Dados Logico

Entidades, atributos e relacionamentos logicos da plataforma PIPPA, organizados por dominio de negocio
Ref.: Item 3.12 do Parecer UTIC — Relatorio de Aderencia para Internalizacao — 09/11/2026

Este documento apresenta o modelo de dados logico da plataforma PIPPA, organizando as estruturas de dados em 5 dominios de negocio. Para cada entidade, sao listados os atributos, tipos logicos, chaves e relacionamentos. O modelo reflete as estruturas efetivamente implementadas no codigo-fonte (dataclasses Python, Parquets, caches JSON/JS e variaveis embarcadas em HTML).

Relacionamentos entre Dominios

Dominio Orcamentario

Emenda → N:1 → Parlamentar (Emendas) via nome_autor (fuzzy match com rapidfuzz, threshold >= 85; confianca: exato|fuzzy|nao_encontrado|nao_aplicavel)
Emenda → N:1 → Municipio (IBGE) via cod_ibge_municipio (normalizado pelo IbgeNormalizer; 7 digitos, primeiros 2 derivam UF)
Emenda → N:1 → UF/Regiao via uf_destino → REGIOES (mapeamento estatico em config.py)
QualityFlag → 1:N → Emenda (agregada) via (uf, ano) — compara totais pagos entre CGU e Tesouro; limiares: 5% alerta, 15% critico
PipelineStats → 1:N → Emenda resume estatisticas de matching (exato, fuzzy, nao_encontrado, nao_aplicavel) sobre todas as emendas processadas
PipelineStats → 1:N → QualityFlag contabiliza flags de alerta e critico geradas na validacao cruzada

Dominio Legislativo

Parlamentar (Stakeholders) → N:M → Frente Parlamentar via parlamentar.frentes[] (lista de titulos, filtrada por keywords relevantes para o Sebrae)
Parlamentar (Stakeholders) → N:M → Comissao via parlamentar.orgaos[] + orgaoRoles{} (mapeamento sigla → papel: Titular/Suplente/Presidente)
Autoria Relevante → N:1 → Parlamentar (Stakeholders) via parlamentar_id; contagem de proposicoes com keywords relevantes (microempresa, MEI, pronampe, etc.)
Candidato TSE 2026 → N:1 → Parlamentar (Stakeholders) via nome normalizado (match estrito TSE x APIs Camara/Senado com overlap de tokens, stopwords removidas)

Dominio Compras Publicas

Contratacao Agregada → N:1 → UF/Regiao via uf → UF_REGIAO (mapeamento UF → NO/NE/SE/SU/CO)
Execucao Orcamentaria → N:1 → UF/Regiao via uf → UF_REGIAO; dados SICONFI/RREO agregados por UF e ultimo bimestre disponivel
PDDE → N:1 → UF/Regiao via uf → UF_REGIAO; transferencias FNDE do Programa Dinheiro Direto na Escola
PNAE → N:1 → UF/Regiao via uf → UF_REGIAO; transferencias FNDE do Programa Nacional de Alimentacao Escolar

Dominio Economico

Arrecadacao RREO → 1:1 → PIB Setorial IBGE distribuicao setorial usada para estimar arrecadacao por setor economico (Servicos, Industria, Comercio, Agropecuaria)

Dominio Monitoramento

Pesquisa Eleitoral → 1:N → Media Ponderada Eleitoral medias calculadas com peso: recencia (half-life 14 dias) x sqrt(amostra) x peso_metodologia (presencial=1.0, telefonica=0.9, mista=0.85, online=0.8)
Pesquisa Eleitoral → 1:N → Cenario Segundo Turno cenarios head-to-head do 2o turno, acumulados incrementalmente via ElectioLab API
