Sobre o PIPPA Stakeholders

O que e o Mapa Parlamentar?

CRM visual de parlamentares relevantes para MPEs. Mapeia deputados e senadores com perfil de atuacao, frentes parlamentares, composicao de comissoes-chave e dados de gabinete — tudo via APIs publicas da Camara e do Senado.

Fontes de Dados

  • Deputados: API Dados Abertos da Camara — /deputados (paginado)
  • Senadores: API Dados Abertos do Senado — /senador/lista/atual
  • Frentes Parlamentares: API Camara — /frentes e /frentes/{id}/membros
  • Comissoes: API Camara — /orgaos e /orgaos/{id}/membros
  • Detalhes individuais: API Camara — /deputados/{id} (gabinete, escolaridade, naturalidade)
  • Eleicoes 2026: TSE CDN — resultados oficiais (resultados.tse.jus.br) para Deputado Federal, Deputado Estadual, Senador, Governador e Presidente

Frentes Parlamentares Relevantes

O filtro de relevancia identifica frentes cujo titulo menciona termos ligados ao ecossistema MPE: empreendedorismo, micro/pequena empresa, Simples, desburocratizacao, inovacao, cooperativismo, credito, turismo, agronegocio, entre outros.

Comissoes-Chave Monitoradas

  • Camara: CDEICS (Desenvolvimento Economico), CFT (Financas e Tributacao), CFFC (Fiscalizacao), CTASP (Trabalho), CCTCI (Ciencia e Tecnologia), CDU (Desenvolvimento Urbano), CE (Educacao), CME (Minas e Energia)
  • Senado: CAE (Assuntos Economicos), CI (Infraestrutura), CDR (Desenvolvimento Regional), CCT (Ciencia e Tecnologia)

Ordenacao

Parlamentares sao ordenados por relevancia: quem participa de mais frentes e comissoes-chave aparece primeiro. O score e calculado como (frentes × 2) + comissoes.

Limitacoes

  • A API do Senado nao expoe frentes parlamentares — apenas deputados sao cruzados com frentes.
  • APIs publicas sem SLA — sujeitas a instabilidade.
  • A composicao de comissoes pode mudar ao longo da legislatura.
