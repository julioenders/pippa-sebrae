📊 Metodologia — PIPPA Regulatório

Fase 1 — Monitor DOU

O PIPPA Regulatório (Fase 1) consulta em tempo real a API pública da Imprensa Nacional (in.gov.br), coletando normas publicadas nas Seções 1 (Atos Normativos) e 3 (Contratos/Licitações) do Diário Oficial da União.

Heurística v2 — 3 Eixos

Cada norma é classificada por três eixos independentes:

Eixo 1 — Relevância Direta MPE (0 a 0.5)

Analisa se o conteúdo menciona o universo MPE. Pontuação máxima por categoria:

  • 0.50 — Menção direta: MEI, microempresa, Simples Nacional, EPP
  • 0.30 — Obrigações: nota fiscal, escrituração, alvará, licenciamento
  • 0.25 — Tributário: IBS, CBS, ICMS, ISS, PIS, COFINS
  • 0.20 — Licitações: pregão, compras públicas, tratamento diferenciado
  • 0.15 — Crédito: financiamento, BNDES, Pronampe

Eixo 2 — Alcance Setorial (0 a 0.3)

  • Até 0.20 — Match com cadeias produtivas (energia, alimentos, saúde, construção, etc.)
  • 0.15 — Regulação de atividade (sanitária, ambiental, trabalhista)
  • Até 0.10 — Tags de Reforma Tributária

Eixo 3 — Potência Normativa (multiplicador)

O tipo de ato funciona como multiplicador, não como pontuação base:

  • ×1.0 — Lei, LC, MP, Emenda Constitucional
  • ×0.9 — Decreto, IN, Resolução
  • ×0.7 — Portaria, Deliberação
  • ×0.5 — Despacho, Aviso, Retificação

Fórmula

score = (Eixo1 + Eixo2) × Multiplicador + Boost órgão (+0.1)

O nível de impacto é derivado do score final:

NívelScoreSignificado
Alto≥ 0.50Afeta diretamente MPEs (menciona MEI/ME/EPP + ato vinculante)
Médio≥ 0.25Impacto indireto ou setorial relevante
Baixo≥ 0.10Potencial impacto marginal
Indefinido< 0.10Sem relevância identificada para MPEs

Fonte de Dados

API pública da Imprensa Nacional (in.gov.br). Consulta em tempo real ao clicar “Consultar DOU”. Cobertura: Seções DO1 e DO3 + edições extras.
